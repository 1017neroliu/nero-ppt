# 场景配置草案

每份 JSON 定义一个内容组织场景，与视觉模板独立。当前为配置草案，尚无运行时加载器。

- `id` 与 `version`：项目需要保存选中版本，配置升级不影响历史任务。
- `required_inputs`：生成前需填写或从资料提取后确认。
- `sections`：推荐顺序，可由用户在大纲审核时调整，不固定总页数。
- `quality_rules`：内容审核规则，运行时需分别实现程序检查、模型检查或人工检查，不能把字符串本身当作已实现校验。
- `notes_requirements`：讲稿约定。
- `missing_evidence_policy`：缺少证据时标注并请求补充，不生成虚构事实。

新增场景沿用同一结构；自动路由只推荐，用户明确选择优先。
