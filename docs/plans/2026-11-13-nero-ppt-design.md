# Nero PPT 轻量工具设计

日期：2026-11-13。状态：设计提案，尚未实施。此方案替代此前多租户平台设计。

## 本轮评审补充

模板适配与能力分析在最终分页前完成，为模型提供可用版式与内容预算。加入来源事实清单、模板槽位约束、程序生成的渲染计划和结构化 QA 报告；自动修复最多 2 轮，不能静默改写已批准事实或版式。详见 [DeepSeek 建议评审与整合方案](2026-11-13-deepseek-review.md)。

## 1. 定位与取舍

做一个用户打开网页即可使用的 PPT 制作工具。核心闭环为：资料与要求 → 场景与模板 → 大纲审核 → 样张审核 → 分批生成审核 → 下载。

保留：场景配置、用户模板、内置模板、真实 PDF 预览、逐页讲稿、局部修改和任务恢复。

暂不做：企业工作空间、成员邀请、角色体系、计费、实时协作、在线拖拽编辑器、分布式调度、自动检索互联网。支持多用户低并发使用，每次制作相互独立。首版建议通过人工发放的独立访问凭据使用；任务与文件归属凭据对应的用户，不能仅靠任务 ID 隔离。无鉴权的本地演示只绑定回环地址，不作为在线交付版本。

## 2. 交互：两个页面

### 新建任务

- 上传资料：首版建议支持文本型 PDF、DOCX、TXT/Markdown、PPTX；扫描件识别和 Excel 工作簿解析后续扩展。不支持时明确提示，不静默遗漏。
- 输入主题、受众、用途、页数范围、预计时长和补充要求。
- 选择场景：工作汇报、客户方案、技术方案；提供“通用/自定义”路径，由用户要求生成建议大纲并确认。现有三个配置是草案，通用路径尚未编码。
- 选择内置模板或上传 PPTX/POTX；模板先检查是否可适配。
- 点击“生成大纲”。需求摘要与大纲一起展示，减少一个审核页面。

### 制作工作台

左侧页面列表，中间 PDF/页面预览，右侧正文要点、讲稿、来源与修改记录。顶部展示阶段和进度。主要操作为编辑大纲、生成样张、提出修改、批准并继续、下载。

同一工作台按阶段显示所需操作，无需复杂管理后台。浏览器刷新后从服务器恢复任务状态。

## 3. 审核与生成节奏

1. 大纲：展示需求摘要、资料缺口、每页标题、核心结论和来源；用户可增删页面并调整顺序。
2. 样张：默认 3 页，覆盖封面、正文和图表/流程等有代表性的版式；用户同时审核讲稿。
3. 正文批次：默认每批 3–5 页，生成并渲染完成后暂停，用户批准再生成下一批。首版不做后台提前生成下一章，减少全局修改带来的返工和调度复杂度。
4. 整稿：生成完整文件，复查页码、目录、转场和引用后下载。

修改意见支持本页、本批和全稿。局部意见重做相关页；模板或结构等全局变化回到对应审核阶段，不做复杂自动依赖推导。系统在执行前展示受影响范围。已经批准的旧版本保留供对比，新版本必须重新批准。

## 4. 场景与模板分离

场景决定内容组织。每个场景配置必要输入、推荐章节、写作提示、讲稿规则及检查项。显式选择优先于自动推荐。新增场景主要增加配置，避免增加一套执行流程。

模板决定视觉形式。内置模板建议准备 2–3 套，每套包含封面、章节页、单栏、双栏、图表、流程和总结版式。上传模板形成自己的版式档案；不必具有全部版式，但缺少所需版式时不能静默用内置样式补齐。

## 5. 用户模板的严格模式

原则：在已有页面和可编辑对象中填充内容，保留固定背景、Logo、字号规则、配色和排版结构。

适配流程：上传 → 解析版式与对象 → 生成缩略图 → 建议封面/正文/图表等用途 → 标记可编辑内容区 → 用户确认必要映射 → 样张验收。自动识别不确定时，允许用户在候选页面中选择用途；复杂模板可先人工适配，保存后复用。

文字优先使用占位符或已标注文本对象，保留段落和富文本样式；不能用粗暴替换整个文本框的方式丢掉格式。图片使用原槽位与裁切规则。复制页面需正确处理资源引用。

内容过长时优先精简、拆页或移入备注/附录。所需版式不足时暂停并提示选择另一个模板页或精简表达。风格扩展可以后续加入，首版严格模式不自动发明新版式。

第一版支持范围是通过样张验收的 PPTX/POTX；POTX 需要正确转换包类型。复杂动画、SmartArt、OLE 等对象可能保留但不支持编辑，逐项报告。PDF/图片参考不归入严格模板支持范围。不能承诺任意文件在所有演示软件中像素级一致。

## 6. 内容与讲稿

模型先整理资料事实与来源，再生成大纲和逐页规格，最后生成正文与讲稿。没有证据的数据标记待补充，不自行虚构。

页面聚焦结论；Notes 包含口述正文、数据解释、转场和建议时长；附录放详细资料。每页记录来源文件与定位信息。用户编辑内容后同步检查对应讲稿。

## 7. 预览与交付

预览必须来自实际生成的 PPTX 转出的 PDF。样张和每批正文输出独立版本，完整预览在整稿时生成。页面缩略图来自相同版本。

最终交付：带逐页 Notes 的 PPTX、幻灯片 PDF、独立 Markdown 讲稿。首版不另做讲稿排版引擎；普通 PDF 不显示演讲者备注。三份文件使用同一生成版本，全部成功后再显示完成。

## 8. 首版验收

- 从上传资料到交付可完成一个完整任务。
- 三个内置场景和通用路径均可调整大纲。
- 至少一套内置模板和一套外部模板完成真实样张验证。
- 字体、背景和固定元素遵守模板；页面无明显溢出、遮挡或占位符残留。
- 审核暂停后刷新网页可继续；旧版本批准不影响新版本。
- 单页修改能重做页面和对应讲稿，不改写无关已批准页。
- PPTX 可在约定的目标软件打开，PDF 与当前版本一致，Notes 存在。
- 少量在线用户不能读取彼此的任务或文件。

## 9. 待实现时决定
